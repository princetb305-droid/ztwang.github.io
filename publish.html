Workflow

发布步骤

  1. 在 D:\blog\posts 新建一篇 .md 文件。
  2. 把文章信息追加到 D:\blog\posts\index.json。
  3. 运行下面的 git 命令发布。
cd D:\blog
git add .
git commit -m "Add new post"
git push
